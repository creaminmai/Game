# Unity 이식 목록

기준은 Godot의 `HospitalSimulation`, `HospitalWorld`와 각 기능의 검증 문서다. Unity 상태는 코드, 에디터 자동 시연, 사용자 수동 조작을 구분한다.

| 범위 | Godot 구현 | Unity 상태 |
| --- | --- | --- |
| 첫날 운영 | 4명 도착, 수동 접수·계획, CT·치료 예약, 선착순과 200만 수입 | 이식. 1명 사용자 확인과 4명 에디터 자동 시연 완료. 모든 시설 FIFO 순서를 바꾼 검사는 코드 검사에서 완료. 최신 수동 클릭은 확인 대기. |
| 내부 3D | 병원·환자·민지 GLB, 카메라와 각 공간, 장비 동작 | GLB·고정 카메라 이식. 에디터에서 렌더·녹화 완료. 환자 복장 구분과 거리 기반 보행을 추가하고 4명 회귀 시연 완료. 장비와 가구 간섭 전수 및 모바일 화면은 미확인. |
| 저장 | 버전 관리 및 Godot 운영 상태 복원 | Unity 별도 버전 5 저장으로 본원·분원·선택 병원·안내를 한 파일에 저장한다. 버전 1–4를 본원 단독으로 읽는다. 재시작한 Unity에서 치료 전후 격리 파일 복원, 단일 보상 확인. 손상 원본 처리와 백업은 코드 검사 완료. |
| 외관·첫 증축 | 외부 전환 시 시간 홀드, 첫 치료 이후 600만, 실제 두 치료실 | 이식. 외부 전환과 시간 홀드, 600만 단일 결제, 두 치료실 배정과 별관 GLB를 에디터 자동 시연으로 확인. |
| 하루와 성장 | 일지, 다음 날, 4명/6명 선택, 챕터 1–4 | 다음 날, 4명/6명 선택, 일일 수지, 1·2장 목표를 이식. 6명 운영과 2개 치료실 저장은 에디터 자동 시연으로 확인. |
| 자동화와 연구 | 2일차 민지 접수, 교육·계획 위임, 연구소와 운영일 연구 | 이식. 에디터 자동 시연에서 교육·위임 4회·연구소·CT 4초와 저장을 확인. 계획 4초 적용은 게임 코드 검사에서 확인. |
| 첫날 이야기 | 민지 환영부터 다음 성장 안내, 재생 상태 저장 | 민지의 환영, 첫 선택·계획·완료·증축·마감 안내와 반복 방지·저장을 이식. 열린 환영 안내의 저장은 에디터에서 확인. Godot의 전체 대사·장면 연출은 남아 있다. |
| 지역 진출 | 시즌 문서 24·25절의 물빛 분원과 운영 네트워크. Godot 게임에는 미구현. | 지도에서 조건을 확인하고 분원을 개설할 수 있다. 본원·분원의 예약과 시설은 독립적이며 공통 날짜·자금으로 운영한다. 에디터 자동 시연에서 지도를 열어 분원으로 이동하고 치료 중 저장 복원 확인. |
| 연구 네트워크 | 연구소와 진료 개선, 병원 네트워크 효과 기획 | 본원에서 적용된 CT·계획 연구를 분원이 공유한다. 다음 공통 운영일에 적용한다. CT 효과와 치료 중 분원 저장은 에디터 자동 시연, 계획 연구 적용 시점은 코드에서 확인했다. |
| 성장 이야기 | 첫날 및 성장 단계 대사 | 첫날 안내에 이어 별관, 위임, 연구소, 분원 안내를 지도에서 표시한다. 확인·전체 건너뛰기를 저장한다. 분원 방문 8회 진행을 표시한다. |
| 장기 기획 | 국내 분원 안정화, 해외 협력병원, 세계 진출 | 물빛 분원 이후의 지역은 잠겨 있다. 시즌 정식 일일 평가, 챕터 보상, 해외 시설은 후속 작업이다. |
| 외부 조건 | 기존 Godot 테스트 빌드 | Mac Apple Silicon 개발 빌드 생성 및 시작 확인. Unity Android/iOS 빌드 모듈과 Xcode·기기 검증 보류. |
