# Unity 이식 목록

기준은 Godot의 `HospitalSimulation`, `HospitalWorld`와 각 기능의 검증 문서다. Unity 상태는 코드, 에디터 자동 시연, 사용자 수동 조작을 구분한다.

| 범위 | Godot 구현 | Unity 상태 |
| --- | --- | --- |
| 첫날 운영 | 4명 도착, 수동 접수·계획, CT·치료 예약, 선착순과 200만 수입 | 이식. 1명 사용자 확인과 4명 에디터 자동 시연 완료. 모든 시설 FIFO 순서를 바꾼 검사는 코드 검사에서 완료. 최신 수동 클릭은 확인 대기. |
| 내부 3D | 병원·환자·민지 GLB, 카메라와 각 공간, 장비 동작 | GLB·고정 카메라 이식. 에디터에서 렌더·녹화 완료. 장비와 가구 간섭 전수 및 모바일 화면은 미확인. |
| 저장 | 버전 관리 및 Godot 운영 상태 복원 | Unity 별도 버전 1 저장 이식. 재시작한 Unity에서 치료 전후 격리 파일 복원, 단일 보상 확인. 손상 원본 처리와 백업은 코드 검사 완료. |
| 외관·첫 증축 | 외부 전환 시 시간 홀드, 첫 치료 이후 600만, 실제 두 치료실 | 이식. 외부 전환과 시간 홀드, 600만 단일 결제, 두 치료실 배정과 별관 GLB를 에디터 자동 시연으로 확인. |
| 하루와 성장 | 일지, 다음 날, 4명/6명 선택, 챕터 1–4 | 다음 날, 4명/6명 선택, 일일 수지, 1·2장 목표를 이식. 6명 운영과 2개 치료실 저장은 에디터 자동 시연으로 확인. |
| 자동화와 연구 | 2일차 민지 접수, 교육·계획 위임, 연구소와 운영일 연구 | 미이식. 지원 조건과 적용 시점은 Godot의 위임·연구 코드 참조. |
| 첫날 이야기 | 민지 환영부터 다음 성장 안내, 재생 상태 저장 | 단계별 HUD 지시 이식. 이야기 이벤트와 반복 방지는 미이식. |
| 장기 기획 | 지역 분원과 세계 진출 기획 | 이번 이식 대상에서 제외. |
| 외부 조건 | 기존 Godot 테스트 빌드 | Unity Android/iOS 모듈과 기기 검증 보류. Mac 에디터만 실행 확인. |
