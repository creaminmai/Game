# 작은 방사선과에서 세계 네트워크로

사용자 승인 방향: 실제 3D 공간, 고정 카메라, 모바일 세로 화면의 따뜻한 병원 운영 게임.
아트는 크림·청록·코랄, 귀여운 작은 인물과 알아볼 수 있는 장비를 결합하는 A+C 방향을 따른다. 기존 승인 이미지 원본은 현재 확보하지 못했다. 현재 기본 도형 모델은 최종 아트가 아니다.

## 장기 성장 방향

| 단계 | 플레이의 중심 | 상태 |
| --- | --- | --- |
| 동네 방사선과 | 접수, CT, 직원 계획 검토, 치료, 첫 별관 | 프로토타입 구현 |
| 지역 거점병원 | 직원 자동 접수·계획, 여러 장비와 업무 배치 | 미구현 |
| 치료시스템 연구소 | 직원 교육, 계획 기술, 장비 안정성과 효율 투자 | 미구현 |
| 여러 지역 병원 | 지역 수요·인력 조건·설립 조건을 비교해 투자 | 미구현 |
| 세계 병원 네트워크 | 지역별 운영 과제와 연구 공유, 해외 진출 | 미구현 |

기본 순환은 환자 치료 → 수입·평판 → 병원·직원·연구 투자 → 운영 능력과 게임 내 성과 향상 → 새 지역 진출이다. 현재 코드는 수입·첫 증축까지 구현했고 평판·연구·지역 진출은 없다.

처음에는 직접 지시하며 운영을 배우고, 이후 일상 업무는 직원에게 맡긴다. 병원 수가 늘어났을 때 접수 버튼을 더 많이 누르게 만들지 않는다. 가격·연구 공식·지역명·해금 조건은 아직 확정하지 않았다. 게임 내 성과를 임상 치료율로 표현하지 않는다.

## 다음 개발 순서

1. 현재 환자 목록·조작 필요·대기 순서에 대한 사용자 플레이 피드백.
2. A+C 방향의 모델과 캐릭터 발전, 직원 자동 운영의 최소 기능.
3. 지역 지도와 두 번째 병원의 작은 운영 단위.
4. 연구소와 병원 간 성장 연결.
5. Android/iOS 빌드 및 실기기 성능·조작 검증.

위 순서는 제작 가설이며 사용자 아이디어와 실제 플레이 결과에 따라 조정한다. 지도 콘셉트 이미지가 실행되는 지도이거나 최종 승인된 화면이라고 취급하지 않는다.
