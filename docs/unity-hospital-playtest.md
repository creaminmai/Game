# Unity 첫 환자 운영 검증

Mac Apple Silicon, Unity 6000.6.9f1, Metal, URP 17.6.0. 대상은 `unity/Assets/Scenes/Hospital.unity`다. 이 기록은 임시 3D 모델을 사용한 첫 운영 구현에 해당한다.

| 증거 | 확인한 결과 |
| --- | --- |
| 에디터 화면 직접 관찰 | 사용자가 연 Game 뷰에 병원과 두 장비가 렌더링됐다. 치료 계획 지시 대기, 선택된 김영수, 운영 자금 900만을 확인했다. |
| 사용자 수동 조작 확인 | 접수 대기 화면에서 시작했고 계획 지시, 5초 검토, 치료실 이동 중 정지와 재개, 치료 타이머의 정지와 재개, 치료 종료와 환자 퇴장을 확인했다. 치료 종료 시 900만에서 1,100만으로 증가했고 퇴장 후에도 유지됐다. |
| 운영 상태 검사 | Unity에 포함된 Roslyn으로 C#을 컴파일했다. 독립 상태 모형 검사 17개를 통과했다. CT 입실 전 서비스 타이머 미진행, CT 5초 및 계획 5초 경계, 치료 30초 직전 지급 차단, 치료 종료 시 단일 지급, 정지 중 타이머와 행동 차단을 포함한다. |
| 에디터 로그 | Unity Personal 라이선스 확인, Package Manager 연결 및 Hospital 장면 로드를 확인했다. 확인한 로그에서 C# 컴파일 오류나 런타임 예외는 발견되지 않았다. |

독립 상태 검사는 CT 화면의 실시간 5초나 클릭 입력을 측정하지 않는다. 에이전트의 Game 뷰 클릭은 Computer Use의 창 오류로 전달되지 않았다. 실시간 CT 화면 측정, Mac 독립 실행 빌드, Web 빌드, Android/iOS 기기, 실제 플레이 영상은 이 기록의 미검증 범위다.
