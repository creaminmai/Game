# Unity 3D 제작과 시즌 진행 검토

기준은 코드 `2f10d2a`와 원격 3D 시안 `92d5f36`이다. [다섯 원본 시안](../reference/art/3d-direction-v1/README.md)을 직접 열어 확인하고 매니페스트 SHA-256을 검증했다. [원격 제작 지침](3d-art-production-direction.md)을 포함했다.

## 제작 관계와 비용

- 기존 `art/source/nurse.blend` → `tools/art/build_characters.py` → `unity/Assets/Resources/HospitalArt/nurse.glb`의 관계를 유지한다. Blender 실행 파일이 확인되지 않은 Mac에서 새 .blend를 만들거나 기존 원본을 덮어쓰지 않았다. [Unity 제작 소스](../unity/Assets/Scripts/HospitalRoom.Presentation.cs)는 그 메시·Head/Arm/Leg 피벗을 그대로 써 두 카메라에서 실시간 렌더하고 앞머리 볼륨, 눈꺼풀, 손가락, 단추와 해바라기 배지를 별도 기하로 붙인다. 얼굴 비율은 기존 2.7등신을 유지한다. 독립 표정 블렌드셰이프와 스킨 리깅은 남아 있다. 기쁨·걱정은 목과 팔 제스처를 사용한다.
- 원본 GLB는 숨겨지는 안경·앉은 다리·책을 포함해 인덱스 기준 47,032삼각형, 14재질, 512×512 PNG 한 장이다. 추가 소품은 공통 저해상도 구 메시를 공유한다. 대화/지도는 서로 다른 culling layer에서 448×512 및 640×368 ARGB32/D16 타깃을 쓰며 해당 창에서만 카메라를 켠다. 색·깊이 버퍼 포맷 기준 약 2.65MiB로 추산한다. 텍스처 압축과 패스별 GPU ms, Android/iOS 성능은 실측하지 않았다.
- 외부 입구에 3D 해바라기 표식, 난간, 벤치를 추가했다. 증축 확인 전 건물 크기의 3D 골조를 띄운다. 기존 비용·예약과 실제 치료실 개방은 유지한다. 내부는 기존 CT와 LINAC 및 고정 카메라를 유지하고 새 민지를 연결했다. 환자 Blender 모델 전면 리모델링은 남아 있다.
- 지도는 실제 깊이를 가진 세 지형 조각, 건물, 나무, 두 연결 통로를 별도 카메라로 렌더한다. 병원 노드는 월드 좌표에서 화면 좌표로 투영된다. 선택 카드의 설립·이동·저장은 기존 코드에 연결되어 있다.

## 시즌 규칙과 이전

- 공동 운영일 09:00–18:00은 정상 속도 360초다. 폐점 전 귀가를 실제 환자 상태 전이에서 세고 본원과 물빛이 각각 예약의 90% 이상을 달성한 날을 세 번 누적한다. 늦은 방문도 기존 진료를 계속 받을 수 있고 시간 내 결과에서 제외된다. 알파의 기존 바다빛 조건에 이 평가를 추가했다.
- 6장 정산은 공동 자금 2,500만·연구점수 최대 10점, 7장 바다빛 첫 운영일 정산은 공동 자금 3,000만이다. 두 상태의 고정 거래 ID에 해당하는 저장 플래그에서 공동 잔액을 계산한다. 반복 정산·복원은 동일 보상을 추가하지 않는다. 1–5장의 기존 보상은 유지했고 신규 평판 보너스는 적용하지 않았다.
- 알파 임시 설계로 6장 이후 병원별 첫 예약 한 자리에 3회 과정을 둔다. 같은 과정 환자의 다음 방문을 우선 배정하고 두 번째·세 번째는 기존 접수에서 치료 FIFO로 바로 보내 CT·계획을 반복하지 않는다. 일반 신규 예약은 기존 흐름을 따른다. 5회·7회 과정과 놓친 예약의 재배정은 남아 있다.
- 실제 접수·계획·장비 대기 상태에서 누적한 시간으로 만족도를 계산한다. 이동과 치료는 대기에 포함하지 않는다. 90점에서 60초 초과분 10초당 2점을 감점하고 40∼90점으로 제한한다. 편의·안내 보너스는 후속 작업이다.
- 세 병원에 실제 과정 완료가 있고, 본원 적용 연구가 6개 이상이며, 그날 완료한 방문의 공동 만족도가 85 이상이면 하루 정산에서 엔딩을 연다. 다시 보기, 이후 계속 운영, 엔딩 대사 위치를 저장에 연결했다. 시즌 조경 보상은 남아 있다.
- 버전 8 이전 저장은 기존 방문·자금·설립·구매를 유지한다. 정시에 마쳤음이 확인되는 현재 날짜 외의 과거 기한 기록, 과정 기록, 신규 보상은 추정 지급하지 않는다. 진행 중인 이전 방문은 기존 경로로 끝난다.

## 실행과 전달

- **독립 검증** 272개 통과. 늦게 귀가한 환자는 영업시간 목표에서 제외된다. 6장 세 번 달성, 바다빛 첫날 보상 1회, 재방문 CT·계획 생략, 과정 완료·여섯 연구·실제 만족도에 묶인 엔딩과 엔딩 저장을 검사했다. 기존 1,530만 정산과 실제 구매액 보존도 회귀 검사에 있다.
- **에디터 자동 시연** Unity 6000.6.9f1 실제 Play에서 3D 민지와 그림자/투명 합성, 정산, 지도, 바다빛 재방문 치료 및 시즌 엔딩에 도달했다. 격리 슬롯에서 끝 대사 두 번째 줄을 복원했다. 후반 운영일을 빠른 도메인 호출로 진행했다.
- **직접 입력** 실제 키보드로 민지 인사 두 줄과 접수 안내를 넘겨 첫 환자를 선택·접수했다. 로그에서 `WalkingToCt`로 진입했다. 지도에서 마우스로 설립·전환하는 조작과 사용자 플레이는 이번에 확인하지 않았다.
- **Mac** arm64 개발 앱 빌드 오류 0. 경로는 `artifacts/unity-overnight/builds/SunshineHospital.app`이다. 이 새 앱의 독립 실행은 미확인이다. 시뮬레이션 시험은 실제 모바일 측정과 별개다.
