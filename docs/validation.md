## 한계

자동 데스크톱 입력 테스트이며 사용자의 수동 플레이테스트가 아니다. 터치 이벤트·Android/iOS 실기기·APK/IPA·모바일 프레임 속도·발열·배터리는 미검증이다. 창 배치 검사가 작은 화면에서 글자를 편하게 읽을 수 있다는 사용자 평가를 대신하지 않는다. 기본 3D 모델과 waypoint 동선은 최종 아트/물리/자유 경로 탐색이 아니다.

Xorg dummy 드라이버는 V-Sync 변경을 지원하지 않는다는 경고를 출력했다. 렌더링과 입력·기능 검증은 완료됐으며 이 경고를 모바일 성능 결과로 해석하지 않는다. 제한된 셸에서는 엔진 editor의 로컬 TCP 포트 생성이 차단될 수 있으며, 그래픽 QA는 로컬 소켓 생성이 허용된 실행에서 수행했다.

## 참고 이미지에 따른 아트 개선 후 재검증

둥근 메시·캐릭터 비율·가구·의료 장비·유리창·복도 마감·건물 외형·조명을 변경한 뒤 운영 테스트 **51개**, 실제 UI 입력 및 장면 검사 **40개**가 모두 다시 통과했다. 이번 그래픽 QA 결과는 `artifacts/art-direction/`에 기록했다. 치료 중 캐릭터가 새 매트리스에 묻히지 않도록 누운 위치를 보정하고 실제 동시 치료 캡처를 확인했다.

`--art-capture`로 1280×960의 내부·외관 확대 화면을 별도로 저장했다. 동일 모델과 조명의 실제 엔진 렌더이며 HUD를 제외했다. 확대 캡처 자체는 기능 테스트 개수에 포함하지 않는다. `docs/images/`의 네 PNG는 이번 화면으로 갱신했다. 참고 이미지와의 완성도 차이와 모바일 성능 미검증 범위는 [아트 기준](art-direction.md)에 기록했다.
