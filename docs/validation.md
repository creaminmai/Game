## 한계

자동 데스크톱 입력 테스트이며 사용자의 수동 플레이테스트가 아니다. 브라우저 터치 에뮬레이션은 별도 검사하지만 Android/iOS 실기기·APK/IPA·모바일 프레임 속도·발열·배터리는 미검증이다. 창 배치 검사가 작은 화면에서 글자를 편하게 읽을 수 있다는 사용자 평가를 대신하지 않는다. 기본 3D 모델과 waypoint 동선은 최종 아트/물리/자유 경로 탐색이 아니다.

Xorg dummy 드라이버는 V-Sync 변경을 지원하지 않는다는 경고를 출력했다. 렌더링과 입력·기능 검증은 완료됐으며 이 경고를 모바일 성능 결과로 해석하지 않는다. 제한된 셸에서는 엔진 editor의 로컬 TCP 포트 생성이 차단될 수 있으며, 그래픽 QA는 로컬 소켓 생성이 허용된 실행에서 수행했다.
