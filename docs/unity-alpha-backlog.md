# Unity 알파 작업 목록

기준 커밋은 `6508ad8`이다. 기존 설정 변경 6개를 보존한다.

| 범위 | 상태 | 기준과 부족한 부분 |
| --- | --- | --- |
| 1. 여러 날 운영 | 검증 완료 | FIFO, 4·6명, 병목 표시, 하루 결과와 직전 정산. 실제 UI 입력은 첫 환자 접수까지 확인했다. 여러 날 일지 목록은 미착수다. |
| 2. 세 병원 | 검증 완료 | 해안 협력병원 추가. 에디터 자동 운영으로 세 곳을 열고 외관과 격리 저장을 확인했다. 지도 마우스 전환은 실행 미검증이다. |
| 3. 연구와 직원 | 구현됨 / 실행 미검증 | 연구 7개와 실제 시간 변화, 직원 위임 연결. 교육 연쇄는 코드 통과, 관리 화면 렌더는 확인. 연구 7종 전체 UI 구매는 미확인이다. |
| 4. 이야기 | 검증 완료 | 실제 키보드로 민지 인사 종료와 접수 확인. 안내 두 번째 줄 복원과 민지 두 표정 확인. 정식 챕터 보상과 추가 표정은 미착수다. |
| 5. 꾸미기 | 구현됨 / 실행 미검증 | 8품목·4슬롯과 UI. 구매 중복 방지·병원 분리 코드 통과. 수동 구매·미리보기·되돌리기와 동선은 전체 미확인이다. |
| 6. 그래픽과 움직임 | 구현됨 / 실행 미검증 | 새 HUD·초상·폰트·아이콘과 주요 16:9 화면 확인. 긴 가로, 모바일, 장비 승하차 전수는 미확인이다. |
| 7. 제품 기본 | 구현됨 / 실행 미검증 | 새 게임 및 별도 보관, 이어하기, 실제 저장, 도움말. Mac에서 시작 화면 표시 확인. 설정 입력과 재실행 복원 전체 아직 미확인이다. 오디오 도입은 미착수다. |
| 8. Mac 통합 검증 | 구현 중 | Mac arm64 개발 앱 생성과 시작 확인. 전체 플레이는 에디터 자동 시연 및 첫 접수 직접 입력에 한정된다. |
| 8. Android·iOS | 외부 조건으로 차단 | 설치된 에디터에서 모바일 빌드 지원 디렉터리를 찾지 못했다. 모바일 기기와 서명은 검증하지 않았다. |
| 검토 자료 원격 공유 | 외부 조건으로 차단 | GitHub 커넥터의 원격 읽기는 성공했다. 로컬 Git 네트워크 DNS 제한으로 푸시는 보류다. |
