# Unity 알파 작업 목록

기준 검토 커밋은 `bc4db3f`다. [UI 검토와 실행 증거](ui-review.md), [알파 설계](unity-alpha-design-decisions.md), [시즌 스토리 차이](unity-season-story-gaps.md)를 함께 본다.

| 범위 | 상태 | 검증과 잔여 범위 |
| --- | --- | --- |
| 4·6명 운영, FIFO, 병목과 직전 정산 | 구현됨 | 코드와 에디터 자동 시연. 실제 입력은 첫 접수까지 확인. 여러 날 일지 목록은 별도 항목이다. |
| 여러 날 일지 목록 | 미착수 | 현재·직전 정산을 화면에 표시한다. |
| 첫날 꾸미기 정산과 가격 보존 | 검증 완료 | 170만 지출, 1,530만 잔액을 Game 뷰에서 확인. 코드로 다음 날 이월·중복 차감·저장을 검사했다. |
| 세 병원과 지도 노드, 상세 카드 | 구현됨 | 코드·에디터 자동 렌더와 별도 저장 복원. 실제 마우스로 두 분원의 선택과 전환 확인. 직접 설립은 미확인이다. |
| 연구 7개, 직원 위임 | 구현됨 | 코드 검사 및 에디터 렌더. 마우스로 각 연구를 구매하는 검사는 미확인이다. |
| 민지 환영과 실제 접수 | 검증 완료 | 키보드 직접 입력·영상 재생. 두 번째 줄 저장 복원은 에디터 자동 시연이다. |
| 첫날에서 연구소까지 성장 대사 | 구현됨 | 도달 조건·두 줄 진행·저장 코드 검사, 에디터 자동 캡처. 여러 날의 직접 플레이는 미확인이다. |
| 분원 및 바다빛 개원 대사 | 구현됨 | 운영 상태와 연결. 후반 대화 전 과정 실제 입력은 미확인이다. |
| 6·7장 평가·공동 거래·알파 엔딩 | 구현됨 | 코드와 Unity 자동 시연에서 정산·재방문·엔딩과 저장 복원 확인. 유저 전체 시즌 완료는 미검증. |
| 과정 5·7회, 놓친 예약 재배정, 시즌 기념 조경 | 미착수 | 알파의 3회 코스와 지속 운영을 검증했다. |
| 민지 v2 메시와 3D 대화 | 구현됨 | 실제 Unity에서 다섯 표정, 회색 실루엣, 마우스 대화 진행, 게임 화면·초상 픽셀 비교. 시안의 표면과 표정에 남은 차이는 [검토 문서](graphics-production-v2.md)에 있다. |
| 3D 실내·외관·지도 | 구현됨 | Unity 자동 캡처와 실제 지도 전환. 모바일 성능과 지역별 모델 세부 제작은 남아 있다. |
| 민지 v2 Blender 저장 | 검증 완료 | Blender 4.5.16 LTS 앱에서 임시 장면을 렌더했다. GLB를 별도 [편집 파일](../art/source/minji-v2.blend)로 저장하고 메시와 여섯 표정 키를 다시 열어 확인했다. |
| 환자 메시와 장비 승하차 리그 | 미착수 | 기존 환자 메시에서 재질만 조정했다. 실시간 환자 1명의 기존 승하차·퇴장 경로는 검사했다. |
| 병원별 장식 8개 | 구현됨 | 중복 비용·병원 분리·날짜 정산 검사 통과. 수동 미리보기·취소·동선 전수 검사는 미확인이다. |
| 새 게임·이어하기·도움말 | 구현됨 | 독립 실행의 전체 입출력 및 재실행 복원은 미확인이다. |
| 긴 화면과 모바일, 장비 승하차 전수 | 미검증 | 이번 검토 화면은 16:9 Unity Game 뷰다. |
| Android·iOS 빌드 | 외부 조건으로 차단 | 모바일 지원 모듈, 기기 및 서명 환경 미확인. |
