# 햇살병원 아트 방향

사용자가 첨부한 따뜻한 병원 인테리어가 시각 기준이다. 크림색 벽, 밝은 목재, 옅은 청록색 의료 장비, 코랄 좌석, 큰 창과 식물, 둥근 인물을 유지한다. 가로 화면의 실제 3D 공간에서 환자 이동·장비 사용·증축이 보이게 한다.

## 이번 작업: 별도 모델과 재질

병원 내부·별관 장비·환자·간호사를 Blender 원본과 게임용 GLB로 분리했다. 모델은 저장소의 Blender Python 코드로 작성했으며 [원본과 재생성 방법](../art/README.md)을 함께 보관한다. 실행 중 기본 도형을 조립하던 내부 장면을 이 모델로 교체했다. 외관 건물은 기존 모델을 사용한다.

- 접수대: 둥근 목재 본체, 외곽을 따르는 얕은 루버, 크림색 상판, 햇살 장식, 모니터·꽃 장식.
- 좌석: 두툼한 좌판·등받이·둥근 팔걸이, 목재 다리, 깨끗한 코랄 직물. 깊은 봉제선과 파이핑을 제거했다.
- 장비: 열린 CT 링, 외장 이음선·조작부·민트색 내장, 침대의 받침·레일·베개. 치료기는 연속된 곡면의 암과 조사 헤드를 사용한다.
- 건축: 창틀, 높은 뒤쪽 벽, 복도의 낮은 벽·열린 문틀·손잡이, 앞쪽 단면 벽. 환자 동선에 문짝을 배치하지 않았다.
- 생활감: 수납장·책장·액자·스탠드·화분과 입구 주변 꽃·잎.
- 인물: 부드러운 얼굴·눈·볼·안경·머리 형태, 깃·주머니·명찰, 손과 신발. 명명된 머리·팔·다리 피벗으로 걷기·업무 자세를 표현하고 대기 중 앉은 다리와 책을 표시한다.

## 재질·조명과 게임 적용

목재와 직물의 표면 색을 텍스처로 굽고, 정적 공간의 접촉 음영은 별도 UV에 128샘플로 굽는다. 캐릭터는 정점 색으로 접촉 음영을 저장한다. 따뜻한 햇살과 보조광·벽 조명을 조정한다. 장비 사용 표시와 치료 빔은 게임 상태에 따라 움직인다.

정적 병원은 큰 곡면을 보호하며 게임용 264,470 삼각형으로 감량하고, 인물의 작은 부품은 움직이는 단위별로 합쳐 그리기 횟수를 줄였다. 텍스처 좌표·패킹·삼각형 예산은 `tools/art/check_assets.py`가 검사한다. Godot가 가져온 AO 재질의 UV 채널과 실제 인물 크기는 엔진 테스트에서 별도로 검사한다.

내부·접수 확대 이미지는 실제 게임 모델·조명을 Godot에서 렌더한 것이다. HUD를 제외하고 고정된 검토 카메라로 전후를 비교한다. 플레이 카메라는 얼굴과 앞면이 더 보이도록 높이를 소폭 낮췄다. Blender 렌더나 생성 이미지를 게임 화면으로 제시하지 않는다. `--art-capture`는 육안 검토용이며 기능 테스트와 구분한다.

## 남은 품질 작업

참고 이미지 수준의 최종 아트가 완성된 것은 아니다. 이번 작업으로 수정 가능한 별도 모델·재질과 검증 과정을 마련했다.

1. 캐릭터의 뼈대·스킨 리깅, 앉기/일어서기 전환, 자연스러운 응대·작업·표정.
2. 목표 시안과 같은 카메라로 비교하며 장비·가구의 실루엣과 재질 반사, 얼굴의 표현과 간접광을 더 정교하게 다듬기.
3. 외관·조경·증축 연결부를 내부와 같은 수준의 별도 모델로 교체.
4. 실제 iPhone/Safari에서 프레임 속도·메모리·발열을 측정하고 LOD·그림자·재질 비용 조정.

연구소·지역 확장 화면은 아직 구현하지 않았다. 현재 포즈는 독립 부품을 움직이는 방식이며 최종 캐릭터 리깅은 아니다.

## 2026-11-04 상세 아트·UI 기준

사용자가 추가한 재질·형태·빛 기준과 게임 UI 시안을 우선한다. [최신 아트 검토](art-review.md)와 [동일 카메라 비교](art-review.html)를 참고한다. 민지는 약 2.7등신의 갈색 단발·청록복이며 피부·머리의 거친 음영을 줄였다. 깊은 타일 틈과 소파 파이핑을 제거하고 코팅 외장·천·목재의 반응을 분리했다. 기존 환자 운영·경로·증축·저장 형식은 보존한다.
