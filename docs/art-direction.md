# 아트 기준 · 사용자가 제시한 햇살병원 이미지

이번 대화에서 사용자가 보여 준 이미지가 향후 제작의 시각 기준이다. 병원 내부, 외관·증축, 연구소·지역 확장을 함께 보여 주는 그림이며 상단에는 햇살병원 / 작은 병원에서 세계로 문구가 있다. 현재 프로젝트의 게임 엔진 화면과 구분한다. 원본 이미지 파일을 저장소에 확보했다고 주장하지 않으며, 여기에는 보이는 디자인 특징과 구현 결정을 기록한다.

## 유지할 특징

- 크림색 벽, 나무 루버·창틀·접수대, 옅은 청록색 의료 장비와 지붕.
- 코랄색 둥근 소파, 타일 바닥, 넓은 창과 햇살, 식물·꽃·벽 조명.
- 큰 머리와 작은 몸, 둥근 얼굴·머리카락·손발, 표정이 읽히는 환자와 직원.
- 알아볼 수 있는 CT 링·침대와 치료기 헤드, 계획실의 모니터·키보드·수납장.
- 물건과 인물의 접지 그림자, 과하게 하얗게 날아가지 않는 따뜻한 조명.
- 실제 3D 공간과 고정 시점. 운영 중 환자 이동·장비 사용·증축이 공간에 반영된다.

## 가로 화면 대표 장면 · 2026-11-04

사용자가 최근 제시한 병원 내부 확대 이미지를 기준으로 가로 화면 제작을 승인했다. 한 화면에 여러 진료실을 배치하고, 접수·대기·CT 장면부터 밝은 목재와 크림·민트·코랄 색감, 부드러운 형태, 생활 소품을 발전시킨다.

CT를 넓고 둥근 전면과 실제 열린 구멍을 가진 메시로 교체했다. 목재 접수대에는 미세한 결을 적용하고 의자에는 두툼한 쿠션을 추가했다. 벽등은 실제 국소 조명을 갖고, 햇살과 보조광을 캡처로 조정해 흰 장비의 형태가 사라지지 않게 했다. 액자·스탠드·찻잔·책과 창 밖 화단을 보강했다. 대기 환자는 앉은 다리 자세를 사용하며 접수하면 서서 이동한다. 첫 환자는 대기 중 책을 펼친다.

## 이전 아트 개선에서 이어지는 구현

연속된 곡면의 둥근 상자 메시를 추가하고 가구·장비 외장을 교체했다. 환자와 직원은 더 큰 얼굴, 눈의 하이라이트·코·입·볼, 머리카락과 깃·이름표를 가진 3D 모델로 수정했다. 표정 애니메이션이나 최종 리깅은 아직 없다.

내부에는 나무 루버 접수대·햇살 장식, 코랄 의자, CT 외장과 조작부, 치료기 헤드, 수납장·책장·키보드·가상 계획 화면·의료 카트·화분·화단·벽 조명·왼쪽 유리창·복도 손잡이를 배치했다. 실제 시뮬레이션의 이동 경로는 유지하며 통로를 비워 두었다.

외관은 청록 경사 지붕·창틀·입구 차양·계단·난간·가로등·나무·꽃과 별관 연결동을 갖췄다. 증축 후 예정지 표지는 숨긴다. 연구소·지역 확장 화면은 아직 구현하지 않았다.

## 품질 수준과 남은 차이

참고 이미지의 완성도를 달성한 상태는 아니다. 현재는 절차적으로 만든 stylized 3D의 첫 아트 개선본이며, 참고 이미지의 섬세한 모델·재질·연출을 위한 작업이 더 필요하다. 특히 다음은 후속 과제다.

1. 피부·헤어·의복의 정교한 모델링과 리깅, 자연스러운 앉기/일어서기 전환·직원 응대·작업 동작. 현재 앉은 자세는 절차적 포즈이며 전환 애니메이션은 아직 없다.
2. 목재·벽·바닥의 텍스처와 부드러운 실내 간접광.
3. 장비 모서리·부속품과 건물 외형을 더 자연스럽게 정리.
4. 장소별 인물 배치와 생활감, 화면에서의 밀도·크기 조정.
5. 실제 모바일 GPU에서 메시·드로콜·투명 재질·그림자 비용 측정 및 최적화.

확대 렌더는 동일한 실제 게임 모델·조명·고정 카메라로 Godot에서 UI를 제외하고 캡처한 것이다. 생성 이미지가 아니며, 기능 검증은 별도 UI 자동 테스트에서 진행했다.

```sh
python3 tools/run-visual-qa.py --art-capture --output-dir="$PWD/artifacts/art-review"
```

`--art-capture`는 화면 검토용이며 테스트 통과를 의미하지 않는다. `./tools/test-godot.sh`와 기본 `python3 tools/run-visual-qa.py`가 운영·입력 검증이다.
