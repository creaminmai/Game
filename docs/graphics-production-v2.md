## 제작 경로와 제작 범위

- 민지 v2는 [형상·표정 제작 소스](../tools/art/build_minji_v2.py)에서 [Unity GLB](../unity/Assets/Resources/HospitalArt/minji-v2.glb)를 재생성한다. 2.03m 모델 좌표에서 정수리와 턱 사이가 약 0.59m다. 원본과 Unity 모델에서 잰 지점의 차이를 고려해 약 3.5등신으로 조정했다. 부드럽게 이어지는 볼·턱·코, 가르마에서 관자놀이 쪽으로 이어지는 머리 다발, 정점 색 볼 마스크, 두 겹 홍채, 눈꺼풀, 단추·주머니·칼라, 길이가 다른 손가락과 밑창을 메시로 만들었다.
- 캐릭터 두 인스턴스가 같은 GLB와 재질을 사용한다. 운영 인스턴스는 걸음에 맞춰 팔·다리 피벗이 움직이고, 대화 인스턴스는 얼굴 모프와 머리·상체·팔꿈치·손목 피벗을 부드럽게 연결한다. 여섯 모프의 저장 값과 Unity에서 읽는 범위가 다를 수 있어 실제 임포트한 프레임 가중치로 변환한다.
- [Blender 변환 스크립트](../tools/art/materialize_minji_v2_blender.py)를 Blender 4.5.16 LTS 앱에서 실행해 GLB를 [편집용 민지 파일](../art/source/minji-v2.blend)로 저장했다. 파일을 다시 열어 로컬 메시 29개, 삼각형 40,512개, 부위 피벗 11개, 여섯 얼굴 셰이프 키를 확인했다. Blender 임포터가 피부 재질을 두 슬롯으로 나눠 저장 파일의 사용 재질은 21개다. 원본 `nurse.blend`와 게임용 GLB는 보존했다.
- 대화는 분리한 상하·외곽 색을 가진 9-slice 프레임, 코랄 배지, 해바라기, 민트 캡슐 버튼을 조합한다. HUD에는 병원과 해바라기, 중앙 자금, 오른쪽 날짜·완료 인원과 일시정지, 아래 가운데 메뉴를 배치한다. 작은 안내의 새 초상은 Unity에서 렌더한 민지의 투명 PNG를 사용한다. 폰트는 저장소의 기존 [주아체·Noto 라이선스 기록](ui-review.md)을 따른다.
- 내부는 장비 배치와 환자 경로를 유지하며 벽·줄눈·민트와 원목의 대비를 조정했다. 환자의 기존 몸과 동작을 활용하고 옷·머리·신발 색을 환자마다 구분했다. 외부에는 층간 띠·처마·창틀·계단·정원과 벤치, 지역별 지붕·강변 난간·해안 산책로를 추가했다. 지도는 하나의 도로로 연결된 두 강둑, 다리·해안·언덕과 병원 실루엣을 실제 메시로 표시한다. 병원 상세 화면과 클릭 좌표는 지도 카메라의 실제 노드에서 가져온다.

## 모델과 렌더 예산

| 항목 | 확인한 값 |
| --- | --- |
| 민지 전체 GLB | 40,512 삼각형, 재질 20개, 외부·내장 텍스처 0개 |
| 캐릭터 소스 | 정점·인덱스·노멀·볼 색상과 얼굴 모프가 GLB에 포함된다. 같은 명령에서 바이트 단위로 재현했다. |
| 대화 초상 | 768×896 RGBA32, 16비트 깊이. 컬러와 깊이 최소 저장량 약 3.94 MiB. 드라이버 정렬·추가 프레임 버퍼 제외 |
| 지도 | 640×368 RGBA32, 16비트 깊이. 최소 약 1.35 MiB. 지도 닫힘 상태에서는 전용 카메라가 렌더하지 않는다. |
| 대화 조명 | 따뜻한 앞 위 스폿과 약한 반대 보조광을 초상 레이어와 별도 위치에 둔다. 대화를 닫으면 초상 카메라와 스폿을 비활성화한다. |

Mac의 사용자 응용 프로그램 폴더에 Blender 4.5.16 LTS Apple Silicon판을 설치했다. 배포본 SHA-256을 공식 목록과 대조했고, 설치 실행 파일에서 빌드 `3f6797307da5`를 확인했다. 셸의 백그라운드 실행은 Metal 초기화에서 중단됐다. 열린 Blender 앱에서는 Cycles CPU로 480×320 임시 장면을 렌더해 `artifacts/blender-verification/temporary-render.png`에 저장하고 실제 파일을 열어 확인했다. [공식 SHA-256 목록](https://download.blender.org/release/Blender4.5/blender-4.5.16.sha256) · [Blender의 Metal 초기화 이슈](https://projects.blender.org/blender/blender/issues/163272)

Mac 에디터에서 동일한 대사 화면으로 초상 카메라 렌더 끔/켬을 번갈아 두 번 측정했다. 2560×1440에서 각각 90프레임을 수집했다. 첫 번째 전체 프레임 중앙값은 1.322→1.583ms, 두 번째는 1.293→1.563ms다. p90은 1.614→1.852ms 및 1.501→1.831ms다. 에디터 전체 프레임 간격이며 GPU 전용 격리 시간이나 모바일 실기기 프레임 속도는 아직 측정하지 않았다.

Linear 색 공간의 기존 IMGUI 합성에서 밤색 머리 픽셀이 초상 PNG RGB `138,98,81`에서 Game 뷰 PNG `195,166,154`로 밝아졌다. 카메라의 선형 색 샘플과 알파를 별도 합성 패스로 보내고 같은 위치를 다시 측정했다. 초상 PNG `138,98,81`, Game 뷰 PNG `138,97,81`이었다. 민트 의상의 표본은 양쪽 모두 `137,183,163`이었다. 표본은 불투명 영역이며 반투명 윤곽은 배경과 정상적으로 합성된다. [Unity DrawTexture의 재질과 화면 좌표](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityengine/graphics/drawtexture)

## 남은 제작 차이

| 영역 | 남은 차이 |

| 얼굴·손 | 승인 시안에는 더 입체적인 입의 내부, 눈두덩과 손가락 관절이 있다. 현재 셰이프 키와 분절 피벗으로 감정과 손바닥 방향을 표현한다. 눈꺼풀 경계 일부와 관절의 연속 표면은 손보아야 한다. |
| 머리 | 단발의 가르마와 꼬리는 연결된다. 측면에서 큰 머리 다발의 경계는 시안보다 뚜렷하고 반사 흐름을 미세하게 다듬을 여지가 있다. |
| 재질·UI | 천은 무광, 피부·머리는 다른 반사 범위로 구분한다. 시안의 직물 미세결과 반투명 피부 효과는 남아 있다. 버튼은 눌림 표면을 제공하며 별도 눌림 위치 애니메이션과 초상의 퇴장 보간은 남아 있다. |
| 내부·환자 | 기존 환자 리그에 색을 맞췄다. 환자 메시 재조형, 승하차용 관절 애니메이션, 모든 시설·환자의 가림과 충돌 전수 검사는 남아 있다. |
| 외관 | 현관·창·처마가 실제 두께를 갖고 지역 환경이 다르다. 실루엣의 본체는 세 지역이 공유한다. 벽체 라운딩, 지역별 건물 본체, 조경 밀도와 개별 간판 모델은 다음 제작 범위다. |
| 지도 | 실제 강과 다리, 육지·해안, 도로, 건물·표찰을 연결했다. 시안의 연속적인 언덕 곡면과 세부 수면·수풀 효과, 잠금 전용 지형 효과는 남아 있다. |

- 직접 Play에서 민지의 다음 버튼 클릭, 두 번째 대사, 대화 종료 및 병원 운영 복귀를 보았다. 별도 파일을 사용하는 44일차 검토 저장에서 지도의 물빛·바다빛 노드와 이동 버튼을 눌러 각 병원 이름과 저장 메시지를 확인했다. 직접 신규 병원 설립은 이번 범위에서 확인하지 않았다.
