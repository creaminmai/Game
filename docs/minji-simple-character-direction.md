# 민지 단순 3D 제작 방향 · 2026-11-22

## 결정과 우선순위

사용자는 검토 브랜치 `36266bd`의 v3를 포함한 기존 민지 결과를 거부하고, 동물의 숲 인간 캐릭터처럼 단순한 표현으로 변경했다. [새 참고 시안](../reference/art/minji-simple-v1/README.md)은 이 방향을 구체화한 생성 이미지이며, 사용자 최종 승인은 아직 받지 않았다.

이 문서는 이전 캐릭터 지시 중 큰 사실적 홍채, 눈꺼풀 조형, 입술과 치아, 머리카락 결, 분리된 손가락, 성인 체형 세부를 요구한 부분을 대체한다. 기존 병원 운영·저장·게임 기획과 가로 화면은 유지한다. 대화 UI와 캐릭터의 표현 방식은 별개로 다룬다.

## 제작 기준

기준 PNG: `reference/art/minji-simple-v1/minji-character-sheet.png`. 오른쪽 위 정면의 전체 비율을 우선하고, 왼쪽 인사와 아래 얼굴은 연출 참고로 쓴다. 동일 시트의 모습들이 완전히 일치하는 정투영 도면이라고 가정하지 않는다.

1. **비율:** 머리카락을 포함한 머리 높이를 H로 잡아 전체 높이 약 2.3~2.5H에서 시작한다. 둥근 큰 머리, 작고 짧은 몸, 짧은 팔다리다. 목은 칼라 뒤에 거의 가린다. 턱은 작고 둥글며 광대·콧대·입 주변의 해부학적 굴곡을 강조하지 않는다. 비율은 실제 이미지 비교로 조정한다.
2. **얼굴:** 얼굴 표면에 붙은 그래픽처럼 보이는 짙은 갈색 세로 타원 눈 두 개, 눈당 작은 흰 점 최대 하나, 작은 곡선 미소다. 흰자 테두리·홍채 무늬·유리 안구·눈구멍·돌출 입술·치아는 만들지 않는다. 코는 피부보다 약간 따뜻한 색의 작은 둥근 삼각형 돌출부다. 코 주변 어두운 그림자를 억제한다. 볼은 작은 연한 코랄색 면이다.
3. **표정 구현:** 머리와 몸은 실제 3D 메시로 만든다. 눈·입·볼은 UV 텍스처 아틀라스 또는 얼굴 곡면에 맞는 얕은 그래픽 메시로 구현할 수 있다. 이는 전체 캐릭터를 평면 이미지로 대체하는 방식과 다르다. UV 이음새·측면 들뜸·깊이 충돌을 확인한다. 복잡한 얼굴 조각·리그보다 기본 눈, 감긴 곡선 눈, 미소 입, 이 없는 작은 열린 입을 일관되게 전환한다.
4. **단발:** 따뜻한 갈색의 매끈한 큰 덩어리 3~5개. 옆으로 흐르는 한 덩어리 앞머리와 볼 양옆을 감싸는 둥근 단발이다. 깊은 골·가는 머리결·물결치는 표면·넓은 흰 광택은 제거한다. 후면도 단정한 둥근 실루엣이다.
5. **몸과 의상:** 완만한 A자 민트 상의, 하나의 흰 둥근 칼라, 작은 크림 단추 두 개, 작은 해바라기 배지와 이름표, 크림 바지, 둥근 청록 신발. 허리·가슴·골반의 성인 해부학적 윤곽과 옷 주름은 강조하지 않는다. 주머니를 넣으면 얕고 단순하게 만든다.
6. **손:** 둥근 장갑형 손과 작은 엄지다. 개별 손가락 네 개, 손톱, 손등 관절은 만들지 않는다. 인사는 어깨·팔꿈치·손목의 작은 회전으로 표현한다. 동작 없이도 손의 외곽이 귀여워야 한다.
7. **재질:** 피부·머리·의상은 금속성 0, 무광 중심이다. URP Smoothness 0.1~0.25를 출발점으로 사용하되 렌더를 보고 조정한다. 천 노이즈·피부 모공·머리 노멀 디테일은 넣지 않는다. 얼굴 그래픽은 조명 때문에 흐려지거나 광택이 생기지 않게 한다.
8. **빛:** 넓고 부드러운 주광과 약한 보조광. 눈 밑·코 아래·입 주변에 짙은 음영을 만들지 않는다. 블룸·회색 막·강한 노란 필터는 피한다. 원본 색, 실제 Game 뷰, 저장 캡처의 일치를 확인한다.

## 구현 순서와 범위

기존 v2·v3 파일과 사용자 저장을 보존하고 새 이름으로 모델을 제작한다. 정상 실행이 확인된 Blender 앱에서 편집·렌더·저장·재열기를 확인한다. Python 사용을 금지하지 않지만 같은 기존 얼굴 생성기를 그대로 재사용해 머리만 키우는 것으로 대체하지 않는다.

먼저 정면 전신과 45도 얼굴의 중립 미소를 만든다. ① 단발 외곽 ② 머리 대 몸 비율 ③ 눈 간격·높이 ④ 작은 입 순으로 시안과 비교한다. 다음으로 인사 손 동작과 웃는 곡선 눈을 연결한다. 기본 외형이 맞기 전에는 다른 캐릭터·환자·아이콘에 확산하지 않는다.

운영용과 대화용은 같은 원본 모델과 얼굴 자산을 사용한다. 대화에서는 얼굴·상반신·인사 손을 크게 보여 준다. 얼굴을 크게 보여주어도 눈알·입술이 사실적으로 변하지 않아야 한다. 머리 몸체, 단발, 의상은 실제 깊이가 있어야 하고, 얼굴 그래픽은 표면 표현으로 한정한다.

기존 민지를 통째로 삭제하지 말고 검토 장면 또는 프리팹 전환으로 비교한다. 승하차 앵커·클릭 판정·장비 예약·진료 타이머를 외형 비율 변경과 함께 임의로 바꾸지 않는다. 사용자 검토 전 최종 채택이라고 보고하지 않는다.

## 제출과 완료 판단

- 시안과 새 Unity 전신을 같은 머리 크기로 나란히 비교한다.
- 정면·45도·후면, 얼굴 근접, 인사·기쁨·설명의 표정 시트를 제출한다.
- 실제 운영 화면에서 약 100~150px 높이인 캐릭터도 눈·머리·근무복이 구별되는지 확인한다.
- 대화 근접 화면과 정상 속도 10~15초 인사 영상을 제공한다.
- .blend, 내보내기 파일, Unity 프리팹, 얼굴 텍스처의 관계를 기록한다.
- 생성 시안, Blender 렌더, Unity 실행 캡처를 구별한다. 컴파일·검사 개수로 디자인 승인 여부를 판단하지 않는다.

이번 저장소 변경은 참고 이미지와 지시만 추가한다. 실제 게임 모델·아트 교체 또는 플레이 검증을 수행한 것이 아니다.
