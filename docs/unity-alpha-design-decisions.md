# Unity 알파 설계 결정

시즌 문서 24절의 해외 해안 도시 협력병원과 평판 65·설립비 20,000 조건을 사용한다. 첫 시즌 원문과 알파 구현의 운영 수치 차이를 이 문서에 기록한다.

## 운영과 데이터

- 바다빛 협력병원은 가상의 해안 도시다. 평판 65, 20,000만, 교육 협력체계 III, 물빛 분원 8회 귀가, 운영 위임과 공통 마감을 요구한다. 기존 알파에는 영업시간 내 완료율 평가가 없어 분원 8회 귀가로 국내 조건을 표현한다. 지원하는 실제 동선 범위에서 해안 병원은 치료실 1곳·9초 간격 예약 4명으로 시작하고 증축하면 두 치료실과 다음 날 6명 예약을 운영한다. 시즌 원문의 해안 기본 치료실 2곳·최대 8명과 다른 임시 범위다. 물빛은 3초 간격 4명, 본원은 6초 간격과 4·6명 선택을 유지한다.
- 알파 연구 7개는 현재 CT·계획·직원 위임 시간에 연결한다. II는 대상 서비스의 4초를 3초로 줄인다. 교육 I·II는 접수·계획 준비를 각각 2초, 교육 III은 두 업무를 1초로 줄인다. 완료의 다음 공통 운영일부터 적용한다. 수치·비용·기간·선행 연구는 `AlphaCatalog.cs`에 모았다.
- 꾸미기는 병원별 네 슬롯의 여덟 선택지다. 미리보기는 자금을 쓰지 않는다. 구매한 장식은 반복 적용할 수 있고 같은 슬롯에서 이전 품목을 교체한다. 비용은 공통 자금으로 지불하고 보유 상태는 병원별로 유지한다. 기록 UI는 당일 환자와 직전 정산을 보여준다.
- 저장 버전 6은 버전 1–5를 읽고 세 병원, 연구, 장식, 직전 정산, 환영 대화 줄을 저장한다. 새 게임은 확인 후 별도 보관본을 복사하고 현재 운영을 새로 시작한다. 사용자가 저장하면 새 운영이 기존 기본 슬롯을 교체한다.
- 평판은 이전 버전의 임시 규칙을 유지한다. 시즌 정식 진료품질·만족도·영업시간 평가와 전체 챕터 보상은 별도 범위다.
