# Mac에서 햇살병원 실행하기

Godot **4.6.3 일반 버전**을 기준으로 만든 프로젝트입니다. GDScript를 사용하므로 .NET 설치는 필요하지 않습니다. ZIP에는 실제 게임 소스, 3D 모델, 재질, 텍스처, 한글 글꼴과 라이선스가 들어 있습니다. Godot 앱은 포함하지 않습니다.

## KMH/05_게임에 설치

1. ZIP을 다운로드하고 더블 클릭해 전체 압축을 풉니다.
2. `햇살병원-Mac` 안의 **KMH에 설치.command**를 더블 클릭합니다.
3. 폴더 선택 창에서 **KMH**를 선택합니다. 이미 그 안의 **05_게임** 폴더를 선택해도 됩니다.
4. `KMH/05_게임/햇살병원`에 프로젝트가 복사되고 Finder와 설치된 Godot을 엽니다. 기존 햇살병원 폴더가 있으면 날짜·시간을 붙인 새 폴더를 사용합니다. 기존 프로젝트와 저장은 삭제하지 않습니다.
5. 첫 리소스 가져오기가 끝나면 Godot 오른쪽 위 **▶ 프로젝트 실행**을 누릅니다. 키보드는 **F5**, Mac 키 설정에 따라 **fn+F5**입니다. F6(현재 장면 실행)과 구분합니다.

Godot이 자동으로 열리지 않으면 앱을 직접 실행하고 **가져오기(Import)** → 위 폴더의 **project.godot** → **가져오기 및 편집**을 선택합니다.

설치 도우미가 열리지 않거나 실행을 원하지 않으면 Finder에서 `햇살병원` 폴더를 `KMH/05_게임`으로 옮기고 같은 방식으로 가져오면 됩니다. 이미 같은 이름이 있으면 새 폴더 이름을 사용하세요. 보안 설정을 바꾸거나 관리자 권한을 사용할 필요는 없습니다.

## 플레이

- 가로 창에서 환자 또는 하단 **환자**를 클릭하고 카드의 **접수하기**로 시작합니다.
- **계획** 지시가 필요할 때 카드에서 진행합니다. 대기·장비 사용은 실제 상태에 따라 자동으로 이어집니다.
- 빈 공간 드래그로 이동, 마우스 휠 또는 **＋ / −**로 확대·축소합니다. **병원** 버튼으로 기본 시점에 돌아옵니다.
- 첫 치료 뒤 **증축**으로 두 번째 치료실을 열 수 있고, 네 환자가 귀가하면 **다음 날**로 진행합니다.
- 자동 저장을 복원하면 일시정지 상태이므로 상단 **재생**을 누릅니다.
- 실행을 멈추려면 Godot의 **■** 버튼 또는 **F8**을 누릅니다.

저장은 Mac의 `~/Library/Application Support/Godot/app_userdata/햇살병원/`에 생성됩니다. 프로젝트 폴더와 별도이며, 같은 게임 이름의 기존 로컬 저장이 있으면 이어서 불러옵니다. 클라우드·웹 브라우저의 저장은 이 ZIP으로 자동 이전되지 않습니다.

첫날 튜토리얼 이전의 저장을 이어가면 새 대사를 강제로 재생하지 않습니다. 기존 진행을 보존하며 새 이야기를 보고 싶다면, Godot에서 최초 가져오기를 마친 뒤 프로젝트 폴더의 **첫날 이야기 체험.command**를 여세요. 첫날부터 시작하며 기존 저장을 읽거나 쓰지 않습니다. 이 체험 창의 진행은 종료하면 사라지고, 일반 F5 실행은 원래 저장으로 이어갑니다. 체험 도우미도 Mac에서의 앱 실행은 별도 확인이 필요합니다.

## 패키지와 확인 범위

패키징 도구는 게임 코드·에셋을 변환하지 않고 커밋된 프로젝트를 복사합니다. 최신 첫날 플레이·별관 완공·병원 일지의 자동 입력 1배속 영상은 GitHub 저장소의 `docs/first-day-polish.html` 및 `docs/media/first-day-*-1x.mp4`에 있습니다. 이전 첫날 이야기 영상은 `docs/first-day-story.html`에 보존합니다. 이전 캐릭터 동작 영상도 `docs/character-motion.html`에 보존합니다.

편집 가능한 Godot 프로젝트입니다. macOS용 독립 실행 .app이 아니므로 Godot으로 엽니다. Blender 원본·Git 기록·클라우드 Web 내보내기 프리셋·엔진 캐시·개인 저장은 제외했습니다. 모델을 수정할 Blender 원본은 GitHub `creaminmai/Game`의 `art/source/`에 보관되어 있습니다.

`패키지-정보.json`에 게임 소스 커밋과 각 파일의 SHA-256을 기록합니다. 2026-11-07의 첫날 이야기 패키지(`764f582`)는 새 폴더에 푼 게임 파일 137개 해시, Godot 4.6.3 최초 가져오기·저장 없는 헤드리스 체험 실행, 이야기 검증 82개를 통과했습니다. 앞선 패키지의 운영 검증 51개도 통과했습니다. 설치 도우미는 셸 구문과 파일 복사·기존 폴더 보존·선택 취소·중첩 복사 방지를 대체 명령으로 검사했습니다. macOS의 Finder 설치 창과 실제 Mac GPU에서의 실행은 이 클라우드에서 검증할 수 없습니다.

개발자가 같은 패키지를 다시 만들 때: 저장소 루트에서 `python3 tools/package-mac-project.py`. 게임 파일은 커밋된 HEAD에서 가져오고 `artifacts/mac/`에 ZIP을 생성합니다.

첫날 개선 버전에서는 왼쪽 아래 **안내 설정**에서 안내를 끄거나 현재 단계부터 다시 켤 수 있습니다. 기존 저장의 과거 증축 지출은 새 일지에서 ‘기록 없음’으로 표시하며, 다음 날부터 실제 거래 기록을 온전히 시작합니다.

첫날 완성도 개선 패키지(`a4af74f`)는 프로젝트 파일 145개 해시와 빈 폴더 최초 가져오기·저장 없는 시작·별관/일지/저장 검사 70개를 통과했습니다. Linux Godot에서 패키지의 완전성을 확인한 것이며 Mac 실기기 GPU 검증을 뜻하지 않습니다.
