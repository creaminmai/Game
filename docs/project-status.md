# 작업 재개 상태 · 2026-11-03

## 확보한 자료

현재 checkout에서 이전 Godot 소스와 ZIP은 발견되지 않았다. 원격에는 초기 README 커밋만 있었다. 사용자 인계서 및 이전 첨부 식별자로 원본 기획서와 HTML을 실제 다운로드해 `reference/`에 보존했다. 과거 환경 자체를 복구하거나 이전 코드와 바이트 단위로 동일하게 복원한 것은 아니다.

## 이번 재구현

- 화면과 독립된 운영 시뮬레이션, waypoint를 따른 이동, 장비 이동 예약 및 FIFO 대기열.
- 대기·CT·계획·치료실과 실제 3D 장비, 직원, 환자, 기본 보행과 눕기.
- 오늘의 환자 4명 목록, 도착 예정·선택·접수/계획 필요·대기 순서 표시.
- 명시적인 조작 필요 환자 이동 버튼. 상태 갱신으로 선택을 강제로 바꾸지 않음.
- 첫 치료 후 600만 증축 확인·취소, 실제 별관·두 번째 장비·동시 치료.
- 안팎 전환 시 일시정지와 이전 재생 상태 복원.
- 치료 완료 시 200만 1회 지급, 귀가 후 다음 날, 자금·별관·누적 인원 유지.
- 검증 후 원자적 로컬 저장, 복원 시 일시정지, 손상되거나 다른 구현의 저장 파일 보존.

## 이전 기록과 다른 범위

이전 55개 테스트 및 영상은 현재 실행 결과가 아니다. 이번 테스트와 화면은 별도 기록한다. 인계서에 있던 `simulation.gd`와 v1 이전 로직은 원본을 확보하지 못해 재현하지 않았다. 현재 저장은 `implementation: sunshine-rebuild-2026-11` 표식을 가진 v2 JSON만 읽는다. 이전 저장은 호환 검토 전에 덮어쓰거나 자동 이전하지 않는다. 원래 v1 파일이 있으면 자동 저장도 중단하고 안내한다.

3D 외관은 운영용 기본 도형이다. 자유 건축, 최종 아트·리깅, 스토리, 수동 계획 퍼즐, 여러 날 치료 과정, 직원 채용/자동 운영, 장기 경제·평판, 지도·연구소, 음악·결제·계정, 모바일 빌드와 스토어 배포는 미구현이다.

## 파일 보관

소스·원본 참고 문서·선택한 실제 엔진 캡처를 커밋한다. 원격 푸시 뒤 원격 main SHA와 로컬 SHA를 비교한다. 푸시 성공이 새 cloud task의 스냅샷 복원 검증을 의미하지는 않는다. 클라우드 설정 저장과 환경 publication 역시 별개이다.

## 사용자 참고 이미지에 따른 첫 아트 개선

사용자가 내부·외관·연구소가 함께 있는 시각 기준을 제시했다. [아트 기준](art-direction.md)에 특징과 남은 차이를 기록했다. 나무 마감·코랄 의자·유리창·실내 소품·둥근 가구·인물·장비 외장을 적용했고 외관과 조명을 조정했다. 초기 형태 표현을 발전시킨 단계이며 참고 이미지 수준의 최종 아트 완성으로 취급하지 않는다.
