# 기획 원문 보관

사용자가 2026-11-03 UTC에 제공한 두 문서를 내용 수정 없이 보관한다. 원문을 구현 현황이나 승인된 제품 수치로 오해하지 않는다. 현재 적용 기준과 충돌 정리는 [제작 기준 메모](../docs/design-baseline.md)를 읽는다.

| 문서 | 내용 |
| --- | --- |
| [첫 시즌 상세 기획 v1.0](season-one-design-v1.0.md) | 본원 운영부터 연구소·국내 분원·첫 해외 병원·8개 챕터·엔딩까지, 시스템·수치·예외·검수 기준 |
| [수익화 제안](monetization-proposal-2026-11-03.md) | 무료 시즌 완주, 꾸미기·추가 이야기, 무료 기념품, 미리보기·가격·추천 빈도·구매 복원 |

[출처·해시 기록](planning-source-manifest.json)에 첨부 식별자, 바이트 수, SHA-256을 남겼다. 이 두 원문은 받은 바이트 그대로이며, 이후 해석·조정은 원문을 덮어쓰지 않고 제작 문서에 기록한다.

기존 자료도 보존한다.

- [이전 인계서](handoff-2026-11-03.md)
- [기존 기획서](original-design.md)
- [기획용 HTML](planning-prototype.html)

사용자의 명시적인 대화 결정이 우선이다. 최신 상세 기획을 향후 기능 설계의 기준으로 참고하되, 이미 합의한 가로 화면과 검증 후 자동 커밋·푸시 원칙은 유지한다.
